# trabalho_N1

Aplicativo Expo/React Native para o Trabalho N1.

## Como rodar

```bash
npm install
npx expo start
```

No output do comando, você encontra opções para abrir o app no Android, iOS ou web.

## Estrutura

- `src/app/` — telas e navegação (Expo Router: cada arquivo aqui é uma rota).
- `src/` — demais códigos do app (componentes, hooks, etc.), fora de `src/app/`.
